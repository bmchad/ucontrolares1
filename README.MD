Nó código, existe um contador que a cada 50ms aumenta em 1% o pwm, aumentado gradativamente de 0 a 100% em 5 segundos e depois diminuindo gradativamente de 100% a 0 em 5 segundos. Além disso, o código testa girar o motor em potência máximo para frente e usar o freio ELETROMAGNÉTICO e depois girar para trás em potência máximo e usar a INÉRCIA DA RODA.
